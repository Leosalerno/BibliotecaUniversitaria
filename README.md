# Sistema de Gestão de Biblioteca Universitária

Projeto desenvolvido para o TP1 da disciplina **Projeto de Bloco: Desenvolvimento Back-End [26E4_5]**.

## Sobre o projeto

O objetivo é desenvolver um sistema para gerenciar uma biblioteca universitária, controlando livros, empréstimos, devoluções, reservas e multas.

Nesta primeira etapa, foi criado um programa simples em Java para simular algumas regras de funcionamento da biblioteca.

## Funcionalidades implementadas

- Consultar a disponibilidade de exemplares.
- Verificar se um empréstimo pode ser realizado.
- Calcular multas por atraso na devolução.
- Verificar se uma reserva pode ser realizada.
